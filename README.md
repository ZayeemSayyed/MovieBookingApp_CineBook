# 🎬 CineBook — Movie Ticket Booking App

An Android application that allows users to browse movies, select showtimes, 
and book seats — built using Android Studio and Java.

## 📱 Features
- Browse available movies
- Select showtimes and available seats
- Simple and intuitive booking interface
- Seat availability tracking

## 🛠️ Tech Stack
- **Language:** Java
- **Platform:** Android
- **IDE:** Android Studio
- **Min SDK:** Android 7.0 (API 24)

## 🚀 How to Run
1. Clone the repository
2. Open in Android Studio
3. Let Gradle sync complete
4. Run on an emulator or physical Android device
